# D{0-1}背包问题求解器 - 使用指南

## 快速开始

### 1. 编译项目

在Windows系统上，双击运行 `compile.bat` 文件，或在命令行中执行：

```bash
compile.bat
```

### 2. 运行程序

编译成功后，双击运行 `run.bat` 文件，或在命令行中执行：

```bash
run.bat
```

或者直接使用Java命令运行：

```bash
java -cp bin com.knapsack.ui.MainFrame
```

## 数据文件格式

### 标准格式

数据文件采用纯文本格式，规则如下：

1. **第一行**：背包容量（浮点数）
2. **后续行**：每3行为一个项集，每行包含两个数值：重量和价值
3. **分隔符**：重量和价值之间用空格或制表符分隔
4. **注释**：以 `#` 开头的行会被忽略
5. **空行**：空行会被忽略

### 示例数据文件

```
# D{0-1}背包问题数据文件
# 第一行是背包容量
100.0

# 第一个项集（3个物品）
45.2 78.5
32.1 56.3
50.0 85.0

# 第二个项集
38.7 62.4
28.5 45.6
42.0 68.0
```

### 测试数据

项目提供了三个测试数据文件：

- `test_data_small.txt`：小规模数据（3个项集）
- `test_data.txt`：中等规模数据（7个项集）
- `test_data_large.txt`：大规模数据（50个项集）

## 功能使用说明

### 1. 打开数据文件

1. 点击菜单栏的"文件" → "打开数据文件"
2. 在文件选择对话框中选择数据文件
3. 系统会自动加载数据并显示在界面上

### 2. 查看数据

- **信息面板**：显示背包容量和项集数量
- **数据表格**：显示所有项集的详细信息
  - 项集ID：项集的编号
  - 物品1/2/3：每个物品的重量和价值
  - 价值/重量比：第三项物品的价值重量比

### 3. 排序数据

点击"按价值/重量比排序"按钮，数据将按第三项物品的价值/重量比降序排列。

排序后，表格中的数据会重新排列，方便查看最优的项集。

### 4. 显示散点图

点击"显示散点图"按钮，会弹出一个新窗口显示数据的散点图：

- **横轴**：重量
- **纵轴**：价值
- **红色点**：物品1
- **蓝色点**：物品2
- **绿色点**：物品3

散点图可以帮助直观地理解数据的分布情况。

### 5. 求解最优解

点击"求解最优解"按钮，程序将使用动态规划算法计算最优解：

- **算法**：显示使用的算法名称
- **求解时间**：显示计算耗时（毫秒）
- **总价值**：所有选中物品的价值之和
- **总重量**：所有选中物品的重量之和
- **选中物品详情**：列出所有被选中的物品

### 6. 导出结果

#### 导出为TXT格式

1. 点击"导出TXT"按钮
2. 选择保存位置和文件名
3. 点击"保存"

TXT文件包含完整的求解结果，格式化输出，便于阅读。

#### 导出为CSV格式

1. 点击"导出CSV"按钮
2. 选择保存位置和文件名
3. 点击"保存"

CSV文件可以用Excel打开，方便进行进一步的数据分析。

## 常见问题

### Q1: 编译时提示找不到类

**A**: 确保已正确设置Java环境变量，并且JDK版本为8或以上。

### Q2: 运行时提示找不到主类

**A**: 检查编译是否成功，确保bin目录下生成了所有.class文件。

### Q3: 数据文件加载失败

**A**: 检查数据文件格式是否正确：
- 第一行必须是背包容量
- 每个项集必须有3个物品
- 每行必须包含两个数值（重量和价值）

### Q4: 散点图显示不正常

**A**: 确保已成功加载数据文件，并且数据格式正确。

### Q5: 求解结果不正确

**A**: 检查数据文件中的重量和价值是否合理，确保第三项物品的价值是前两项之和，重量小于前两项之和。

## 算法说明

本项目使用动态规划算法求解D{0-1}背包问题：

1. **状态定义**：dp[i][j] 表示前i个项集在容量为j时的最大价值
2. **状态转移**：对于每个项集，尝试选择三个物品中的每一个
3. **回溯求解**：从最优状态回溯，得到选中的物品列表

算法时间复杂度：O(n * W)，其中n是项集数量，W是背包容量。

## 性能说明

- 小规模数据（< 10个项集）：求解时间 < 10ms
- 中等规模数据（10-50个项集）：求解时间 < 100ms
- 大规模数据（50-100个项集）：求解时间 < 1000ms
