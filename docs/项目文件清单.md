## 八、使用流程

### 8.1 快速开始
1. 双击 `compile.bat` 编译项目
2. 双击 `test.bat` 运行测试
3. 双击 `run.bat` 启动GUI程序

### 8.2 Eclipse开发
1. 导入项目到Eclipse
2. 运行 `KnapsackTest.java` 进行测试
3. 运行 `MainFrame.java` 启动GUI

### 8.3 功能测试
1. 加载测试数据文件
2. 查看数据列表
3. 进行数据排序
4. 显示散点图
5. 求解最优解
6. 导出结果文件

## 九、注意事项

1. **编译环境**：需要JDK 17.0.17
2. **编码格式**：所有文件使用UTF-8编码
3. **路径问题**：确保在项目根目录下执行脚本
4. **资源文件**：测试数据文件位于 `src/resources/` 目录
5. **输出目录**：编译后的class文件位于 `bin/` 目录
