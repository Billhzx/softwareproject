# 实验二 个人项目实验报告

## 一、需求分析

### 1.1 问题背景
D{0-1}背包问题是经典0-1背包问题的拓展形式，用于对实际商业活动中的折扣销售、捆绑销售等现象进行最优化求解。该问题要求从给定的一组项集中选择满足要求的项装入背包，使得装入背包所有项的价值系数之和达到最大，同时不超过背包的载重量限制。

### 1.2 核心需求
根据实验要求，程序需要实现以下基本功能：

1. **数据读取功能**：能够正确读取实验数据文件中的有效D{0-1}KP数据
2. **数据可视化功能**：能够绘制任意一组D{0-1}KP数据以重量为横轴、价值为纵轴的数据散点图
3. **数据排序功能**：能够对一组D{0-1}KP数据按项集第三项的价值:重量比进行非递增排序
4. **最优解求解功能**：用户能够自主选择指定D{0-1}KP数据并获得最优求解结果
5. **结果保存功能**：任意一组D{0-1}KP数据的最优解、求解时间和解结果可保存为txt文件或导出Excel文件
6. **用户界面**：提供一个友好的用户界面

### 1.3 技术要求
- 使用动态规划算法求解D{0-1}背包问题
- 代码严格遵循《阿里巴巴Java开发手册》或《腾讯C++编码规范》
- 项目必须包含src文件夹
- 将项目源码提交到Github仓库

  3. 记录选择状态choice[i][j]
  4. 回溯得到最优解

### 3.2 关键函数流程图

#### 3.2.1 动态规划求解流程

```
开始
  ↓
读取问题数据（容量、项集）
  ↓
初始化动态规划表dp[n+1][W+1]
  ↓
初始化选择记录表choice[n+1][W+1]
  ↓
for i = 1 to n:
  for j = 0 to W:
    dp[i][j] = dp[i-1][j]
    for k = 0 to 2:
      if j >= weight[i][k]:
        if dp[i-1][j-weight[i][k]] + value[i][k] > dp[i][j]:
          dp[i][j] = dp[i-1][j-weight[i][k]] + value[i][k]
          choice[i][j] = (1, k)
  ↓
回溯得到最优解
  ↓
计算总价值和总重量
  ↓
返回求解结果
  ↓
结束
```

#### 3.2.2 数据读取流程

```
开始
  ↓
打开文件
  ↓
读取第一行（背包容量）
  ↓
while 还有行:
  读取下一行
  if 行为空或注释行:
    continue
  解析重量和价值
  创建Item对象
  添加到当前ItemSet
  if 当前ItemSet已满:
    添加到KnapsackProblem
    创建新的ItemSet
  ↓
关闭文件
  ↓
返回KnapsackProblem对象
  ↓
结束
```

## 五、代码片段展示

### 5.1 动态规划核心算法

```java
public SolutionResult solve(KnapsackProblem problem) {
    long startTime = System.currentTimeMillis();
    SolutionResult result = new SolutionResult();
    result.setAlgorithm("Dynamic Programming");

    List<ItemSet> itemSets = problem.getItemSets();
    int n = itemSets.size();
    double capacity = problem.getCapacity();

    int intCapacity = (int) (capacity * PRECISION_FACTOR);

    int[][] dp = new int[n + 1][intCapacity + 1];
    int[][][] choice = new int[n + 1][intCapacity + 1][2];

    for (int i = 1; i <= n; i++) {
        ItemSet itemSet = itemSets.get(i - 1);
        for (int j = 0; j <= intCapacity; j++) {
            dp[i][j] = dp[i - 1][j];
            choice[i][j][0] = 0;
            choice[i][j][1] = -1;

            for (int k = 0; k < 3; k++) {
                int weight = (int) (itemSet.getItem(k).getWeight() * PRECISION_FACTOR);
                int value = (int) (itemSet.getItem(k).getValue() * PRECISION_FACTOR);

                if (j >= weight) {
                    int newValue = dp[i - 1][j - weight] + value;
                    if (newValue > dp[i][j]) {
                        dp[i][j] = newValue;
                        choice[i][j][0] = 1;
                        choice[i][j][1] = k;
                    }
                }
            }
        }
    }

    int maxValue = dp[n][intCapacity];
    result.setTotalValue(maxValue / (double) PRECISION_FACTOR);

    int currentWeight = intCapacity;
    List<SelectedItem> selectedItems = new ArrayList<>();

    for (int i = n; i > 0; i--) {
        if (choice[i][currentWeight][0] == 1) {
            int itemIndex = choice[i][currentWeight][1];
            ItemSet itemSet = itemSets.get(i - 1);
            double weight = itemSet.getItem(itemIndex).getWeight();
            double value = itemSet.getItem(itemIndex).getValue();

            selectedItems.add(new SelectedItem(
                    itemSet.getId(),
                    itemIndex,
                    weight,
                    value
            ));

            currentWeight -= (int) (weight * PRECISION_FACTOR);
        }
    }

    double totalWeight = 0;
    for (SelectedItem item : selectedItems) {
        totalWeight += item.getWeight();
    }
    result.setTotalWeight(totalWeight);

    result.setSelectedItems(selectedItems);

    long endTime = System.currentTimeMillis();
    result.setSolveTime(endTime - startTime);

    return result;
}
```

**说明**：这是动态规划算法的核心实现。首先将浮点数转换为整数以提高精度，然后构建动态规划表。对于每个项集，尝试选择三个物品中的每一个，记录最优选择。最后通过回溯得到完整的解。

### 5.2 数据文件读取

```java
public KnapsackProblem readFile(String filePath) throws IOException {
    try (BufferedReader reader = new BufferedReader(new FileReader(filePath))) {
        String line;
        int lineNumber = 0;
        double capacity = 0;
        List<ItemSet> itemSets = new ArrayList<>();
        int itemSetId = 0;
        Item[] currentItems = new Item[ITEMS_PER_SET];
        int itemIndex = 0;
        int itemId = 0;

        while ((line = reader.readLine()) != null) {
            lineNumber++;
            line = line.trim();
            if (line.isEmpty() || line.startsWith("#")) {
                continue;
            }

            if (lineNumber == 1) {
                try {
                    capacity = Double.parseDouble(line);
                } catch (NumberFormatException e) {
                    throw new IOException("Invalid capacity format at line " + lineNumber);
                }
            } else {
                String[] parts = line.split("\\s+");
                if (parts.length >= 2) {
                    try {
                        double weight = Double.parseDouble(parts[0]);
                        double value = Double.parseDouble(parts[1]);
                        currentItems[itemIndex] = new Item(itemId++, weight, value);
                        itemIndex++;

                        if (itemIndex == ITEMS_PER_SET) {
                            itemSets.add(new ItemSet(itemSetId++, currentItems));
                            currentItems = new Item[ITEMS_PER_SET];
                            itemIndex = 0;
                        }
                    } catch (NumberFormatException e) {
                        throw new IOException("Invalid item format at line " + lineNumber);
                    }
                }
            }
        }

        KnapsackProblem problem = new KnapsackProblem(capacity);
        for (ItemSet itemSet : itemSets) {
            problem.addItemSet(itemSet);
        }

        return problem;
    }
}
```

**说明**：这个方法负责读取数据文件。第一行是背包容量，后续每3行构成一个项集。支持注释行和空行，提供详细的错误处理。使用try-with-resources确保资源正确释放。

```java
@Override
protected void paintComponent(Graphics g) {
    super.paintComponent(g);
    Graphics2D g2d = (Graphics2D) g;
    g2d.setRenderingHint(RenderingHints.KEY_ANTIALIASING, RenderingHints.VALUE_ANTIALIAS_ON);

    int width = getWidth();
    int height = getHeight();

    g2d.setColor(Color.BLACK);
    g2d.setFont(new Font("Arial", Font.BOLD, 16));
    FontMetrics fm = g2d.getFontMetrics();
    int titleWidth = fm.stringWidth(title);
    g2d.drawString(title, (width - titleWidth) / 2, 25);

    if (itemSets == null || itemSets.isEmpty()) {
        g2d.setFont(new Font("Arial", Font.PLAIN, 14));
        g2d.drawString("无数据", width / 2 - 20, height / 2);
        return;
    }

    double maxWeight = 0;
    double maxValue = 0;

    for (ItemSet itemSet : itemSets) {
        for (int i = 0; i < 3; i++) {
            double weight = itemSet.getItem(i).getWeight();
            double value = itemSet.getItem(i).getValue();
            if (weight > maxWeight) maxWeight = weight;
            if (value > maxValue) maxValue = value;
        }
    }

    maxWeight *= 1.1;
    maxValue *= 1.1;

    int chartWidth = width - 2 * PADDING;
    int chartHeight = height - 2 * PADDING;
    int originX = PADDING;
    int originY = height - PADDING;

    g2d.setColor(Color.GRAY);
    g2d.drawLine(originX, originY, originX + chartWidth, originY);
    g2d.drawLine(originX, originY, originX, originY - chartHeight);

    Color[] colors = {Color.RED, Color.BLUE, Color.GREEN};
    String[] labels = {"物品1", "物品2", "物品3"};

    for (int k = 0; k < 3; k++) {
        g2d.setColor(colors[k]);
        for (ItemSet itemSet : itemSets) {
            double weight = itemSet.getItem(k).getWeight();
            double value = itemSet.getItem(k).getValue();

            int x = originX + (int) (chartWidth * weight / maxWeight);
            int y = originY - (int) (chartHeight * value / maxValue);

            g2d.fillOval(x - POINT_RADIUS, y - POINT_RADIUS,
                        POINT_RADIUS * 2, POINT_RADIUS * 2);
        }

        g2d.setColor(colors[k]);
        g2d.fillRect(originX + chartWidth + 20, originY - chartHeight + k * 30, 15, 15);
        g2d.setColor(Color.BLACK);
        g2d.drawString(labels[k], originX + chartWidth + 40, originY - chartHeight + k * 30 + 12);
    }
}
```

**说明**：这个方法负责绘制散点图。首先计算数据的最大值以确定坐标轴范围，然后绘制坐标轴和数据点。使用不同颜色区分三个物品，并显示图例。

## 六、总结

### 6.1 模块化设计原则的实现

本项目在设计和实现过程中，严格遵循了软件设计的模块化原则，主要体现在以下几个方面：

#### 6.1.1 高内聚低耦合
- **模型层**：专注于数据结构的定义，不依赖其他层
- **算法层**：专注于算法实现，通过接口与模型层交互
- **输入输出层**：专注于文件读写，独立于业务逻辑
- **用户界面层**：专注于界面展示，通过调用其他层实现功能
- **工具层**：提供通用工具函数，可被其他层复用

#### 6.1.2 单一职责原则
每个类都有明确的职责：
- Item类：表示单个物品
- ItemSet类：表示一个项集
- KnapsackProblem类：表示完整的背包问题
- DynamicProgrammingSolver类：负责求解算法
- DataFileReader类：负责文件读取
- ResultExporter类：负责结果导出
- MainFrame类：负责用户界面

#### 6.1.3 接口隔离原则
各层之间通过明确的接口进行交互，避免了不必要的依赖：
- 算法层只需要知道KnapsackProblem的结构
- 界面层通过调用算法层和IO层的公共方法实现功能
- 各层可以独立开发和测试

#### 6.1.4 开闭原则
系统具有良好的扩展性：
- 可以轻松添加新的算法实现（如贪心算法、遗传算法等）
- 可以添加新的数据可视化方式
- 可以添加新的结果导出格式
- 不需要修改现有代码即可扩展功能

#### 6.1.5 依赖倒置原则
高层模块不依赖低层模块，都依赖于抽象：
- MainFrame依赖于DynamicProgrammingSolver的接口
- 可以通过配置或工厂模式切换不同的算法实现
- 便于进行单元测试和模拟

### 6.2 模块化的优势

1. **可维护性**：每个模块职责明确，修改某个功能时不会影响其他模块
2. **可测试性**：每个模块可以独立测试，提高测试效率
3. **可复用性**：工具类和算法可以在其他项目中复用
4. **可扩展性**：可以方便地添加新功能而不修改现有代码
5. **团队协作**：不同成员可以并行开发不同模块

### 6.3 改进方向

虽然本项目已经实现了较好的模块化设计，但仍有改进空间：

1. **引入设计模式**：可以使用工厂模式创建算法实例，使用策略模式切换不同的排序方式
2. **接口抽象**：可以为算法层定义接口，支持多种算法实现
3. **依赖注入**：可以使用依赖注入框架管理模块之间的依赖关系
4. **配置管理**：可以将配置信息（如算法参数）提取到配置文件中
